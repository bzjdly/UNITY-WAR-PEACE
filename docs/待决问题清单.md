## 已解决（2026-09-23，Q16 战略地图结构与移动）

| 原编号 | 问题 | 结论 |
| --- | --- | --- |
| A1-1 | 战略地图如何移动 | 不设格子，移动时自动遵循最短路径 |
| A1-2 | 哪些地方可以通行 | 除高山和地图边界外都可以通行，暂时不考虑水路 |
| A1-3 | 道路与地形如何影响移动 | 道路只改变行动体力的消耗；树林、沼泽、山路等复杂路况显著消耗行动体力 |
| A1-4 | 能否离开道路自由行走 | 可以 |
| A1-5 | 同一位置能否有多支部队 | 不设格子，但部队有碰撞体积，不能重合 |
| A1-6 | 边界与不可通行区域 | 边界暂设为无穷的海洋或高山；不可通行区域无法被移动指令选中，寻路自动避开，无法避开时提示不可通行 |
| A2-1 | 地形对行军、遭遇和战斗入场的影响 | 复杂地形消耗补给并造成减员等负面效果，特殊路段有特殊事件；战斗入场地形与遭遇时的战略地图相同 |
| A2-2 | 城镇、村落和据点如何布置 | 在战略地图上有模型显示；分布方式仍待定 |
| A2-3 | 战争迷雾 | 推迟到制作后期 |
| A2-4 | 遭遇检测 | 需要主动选中，战略地图上距离小于一定距离后进入遭遇流程 |
| A2-5 | 战略地图的制作与调试 | 暂时不处理 |

同时固定了三个术语：**战略地图**（即大地图，不设格子，用于总览局势与城镇运营）／**战斗地图**（设格子，即时战斗用）／**建筑网格**（城镇内部建筑规划，与战略地图无关）。

## C. 制作阶段细化（不阻塞设计）

`大纲.md` 第六章“制作阶段补充”和 Q07、Q14 已明确：以下内容在制作时直接落实到 Data 和代码，不再占用设计问答：

- 《绝境北方》同款操作包含的具体行为范围；暂停时允许执行的具体战斗操作。
- 编队攻击、转向、阵型和指令响应细节。
- 首版兵种、阵型、地形和克制关系。
- 战斗地形的具体生成规则；障碍、道路和高差对单位的具体影响；玩家与敌人的出生位置规则。
- 城镇幸福度影响战斗的 Data 公式或数据项。
- 阵亡、受伤、撤退和补充规则；战后运回、占领城镇和接管流程。
- 战斗胜负条件；敌人 AI 的行为和决策优先级。
- 敌人类型与场景参数的 Data 调试方式。
- 战略层移动与地形（Q16 已定规则，数值待填）：行动体力消耗曲线、道路加成、补给损耗、减员与特殊事件的触发规则、遭遇判定的距离阈值。这些属于数量型内容，按 Q01 全局约束由 Data 控制，不通过设计问答固定。
- 经营侧：网格尺寸、建筑占格、道路连接和相邻加成；人口增长、岗位分配、食物消耗与兵员转化（`大纲.md` 第五章 待决定；框架第十五章）。

说明：经营侧一行虽然列在第五章“待决定”，但按 Q05 的暂缓决定和“战斗优先”的优先级，可以等第二阶段真实实现建筑与人口时再定；如你希望提前定，把它们提到 A 档即可。

## D. 首版明确不做

多人模式；Mod 支持与玩家自制地图；第一阶段接入经营系统、战略层、遭遇切换和自动结算；照搬《文明6》的完整科技、市政、区域和全球运营体系；《绝境北方》式纯防守循环；首版同时完成领主、土匪、海盗等多条完整路线；一开始就做过大的开放世界；核心战斗与经营循环跑通前投入大量复杂城镇内容；战斗系统完成前深挖文明式运营和外交系统。

出处：`大纲.md` 第八章 首版明确不做、第七章 玩家路线与玩家身份。
